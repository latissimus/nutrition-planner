# MUSCLEDEX Slab Icons

Eigenständiges SVG-Iconset für MUSCLEDEX. Die Formen wurden für dieses Projekt
auf einem 24×24-Raster gezeichnet und orientieren sich an kräftigen,
abgerundeten Slab-Konturen. Jedes Symbol besitzt zusätzlich einen harten,
nach rechts unten versetzten Schlagschatten in MUSCLEDEX-Braun `#492426`.

## Verwendung

Die Icons verwenden `currentColor` und übernehmen dadurch die CSS-Textfarbe:

```html
<img src="/icons/ui/search.svg" alt="">
```

Für eine direkte Farbsteuerung können die SVGs inline eingebunden werden.
Standardmäßig verwenden alle Icons `stroke-width="2.6"`, runde Linienenden,
runde Verbindungen und `drop-shadow(1.1px 1.25px 0 #492426)`.

## Ordner

- `categories/` – Hauptbereiche der App
- `food/` – Ernährung, Getränke und Supplements
- `health/` – Körperwerte, Schlaf und Aktivität
- `ui/` – Navigation, Eingaben und Aktionen

Die Icons sind originäre Projektassets und enthalten keine kopierten
Font-Awesome- oder Lucide-Pfade.
